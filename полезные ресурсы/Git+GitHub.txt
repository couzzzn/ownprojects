Установка имени пользователя и email глобально:
Глобальные настройки применяются ко всем репозиториям на вашем компьютере. Для этого используется флаг --global.


git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
Установка имени пользователя и email для конкретного репозитория:
Если нужно задать имя пользователя и email только для одного репозитория, можно выполнить команды в его директории без флага --global.

git config user.name "Ваше Имя"
git config user.email "ваш.email@example.com"
Просмотр текущих настроек:
Вы можете проверить текущие настройки с помощью следующих команд:

Для глобальных настроек:


git config --global user.name
git config --global user.email
Для локальных настроек (в пределах текущего репозитория):


git config user.name
git config user.email
Удаление настроек:
Чтобы удалить глобальные настройки, выполните:

bash
Копировать код
git config --global --unset user.name
git config --global --unset user.email
Чтобы удалить локальные настройки, выполните:


git config --unset user.name
git config --unset user.email
Примечание:
Если вы не зададите имя пользователя и email, Git может запросить их при первом коммите, либо использовать системные настройки. Это важно, так как каждый коммит в истории Git ассоциируется с автором, идентифицируемым по этим данным.
